# Audio Bridge

ПК ↔ Android, полный дуплекс (звук ПК → телефон, микрофон телефона → ПК), три транспорта:
Wi-Fi, USB (через adb reverse), Bluetooth (RFCOMM). Формат протокола и обоснование выбора
кодеков — в [PROTOCOL.md](PROTOCOL.md).

- `pc-server/` — сервер на .NET 8 / WinForms (NAudio для WASAPI, Concentus для Opus, InTheHand.Net.Bluetooth для RFCOMM)
- `android-app/` — Android-приложение на Kotlin (минимум Android 8.0 / API 26)

## Быстрый старт

### 1. ПК-сервер

```bash
cd pc-server/AudioBridge.Server
dotnet run
```

В окне:
1. Выбери устройство, с которого захватывать звук (или оставь "по умолчанию").
2. Выбери устройство, куда выводить микрофон телефона.
3. Нажми **Старт** — поднимутся TCP-слушатель (Wi-Fi + USB) и Bluetooth-слушатель.

### 2. Android-приложение

APK уже собран: `android-app/app/build/outputs/apk/debug/app-debug.apk`.

Установка через adb (провод или уже подключённый Wi-Fi-adb):
```bash
adb install -r android-app/app/build/outputs/apk/debug/app-debug.apk
```
Либо открой `android-app/` в Android Studio и нажми Run.

### 3. Подключение

**Wi-Fi** — ПК раздаёт Wi-Fi (Mobile Hotspot), в приложении выбери режим Wi-Fi, впиши IP ПК
(обычно `192.168.137.1` для стандартной раздачи Windows) и порт `57120`, жми "Подключиться".

**USB** — воткни телефон кабелем, включи USB-отладку. На ПК в поле `adb.exe` укажи путь
(по умолчанию подставится `F:\platform-tools\adb.exe`, если он есть) и нажми **adb reverse (USB)** —
это выполнит `adb reverse tcp:57120 tcp:57120`. В приложении выбери режим USB, жми "Подключиться"
(порт тот же, IP не нужен — коннект идёт на `127.0.0.1`).

**Bluetooth** — сначала спарь телефон и ПК как обычно через настройки Bluetooth Windows/Android
(это отдельное сопряжение, не имеет отношения к A2DP-колонке — используется только чтобы оба
устройства знали друг друга для RFCOMM). В приложении выбери режим Bluetooth, выбери ПК из списка
сопряжённых устройств, жми "Подключиться".

## Почему так, а не иначе

- **Raw PCM float32 на Wi-Fi/USB, Opus 320kbps на Bluetooth** — на Wi-Fi/USB пропускной способности
  много, поэтому звук идёт вообще без сжатия, бит-в-бит из микшера Windows (важно, раз приёмник —
  Xperia 1 IV с хорошим ЦАПом). Bluetooth Classic (RFCOMM) физически не тянет сырой стерео-поток
  с запасом по джиттеру, поэтому там Opus — но на таком битрейте это практически неотличимо от
  lossless, и работает надёжнее прямого A2DP.
- **Не A2DP/LDAC** — LDAC существует только как кодек профиля A2DP, реализуется Bluetooth-стеком/
  прошивкой, и в него нельзя передать микрофон обратно (A2DP однонаправленный). Поэтому Bluetooth
  здесь — свой RFCOMM-канал с собственным протоколом, а не системное подключение "как колонка".
  Подробности и альтернативы — в PROTOCOL.md.
- **Один и тот же TCP-порт для Wi-Fi и USB** — `adb reverse` просто туннелирует локальный порт
  телефона на порт ПК, поэтому серверу не нужно ничего знать про USB отдельно.

## Известные ограничения / что не сделано

- Реконнект есть (2 сек между попытками, детект мёртвого соединения по PING/9 сек), но не покрыт
  тестами на реальных обрывах связи — если заметишь зависания, дай знать.
- Nет UI-настройки битрейта Opus/чувствительности микрофона — сейчас захардкожено в
  `Codecs.cs` / `Codecs.kt` (320kbps музыка, 32kbps голос).
- APK собран как debug (не подписан релизным ключом) — для личного использования это нормально,
  для распространения нужно будет подписать релизным keystore.
